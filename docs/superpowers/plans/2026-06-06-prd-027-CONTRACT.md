# PRD-027 — Envio Rápido & Biblioteca de Ativos — CANONICAL CROSS-PLAN CONTRACT

> **Status:** Authoritative contract. Plans A, B and C MUST consume the names, paths and signatures defined here **verbatim**. If a plan needs a different name/signature, it edits THIS file first and re-pins, never diverges silently.
>
> **Sources:** Design spec `docs/superpowers/specs/2026-06-06-prd-027-envio-rapido-design.md` (D-1..D-16, §3..§5) and PRD `docs/prds/PRD-027-envio-rapido-biblioteca-ativos.md` (RF-001..RF-026, RNF-001..RNF-007). Gold reference for every wiring/mirroring pattern: the PRD-026 media feature.
>
> **Hard rules (repeat):** pagination is `IPaginatedResult<T>.data` (NEVER `.items`). RBAC action vocabulary is `view`/`create`/`edit`/`delete`/`approve` ONLY — do NOT invent a `send` action (confirmed from `src/features/rbac/permissions/matrix.ts` `CRUD`/`CRUDA`). UI strings pt-BR with accents; identifiers English. `division: "parts"` default on commercial entities. Files under `worktrees`/`.superpowers` are out of scope.
